# Personal Website Project

## Website Description
This is a personal portfolio website designed to showcase my projects, skills, and background as part of the ICT251 coursework.

## Website Structure
* `index.html`: The main homepage containing structural markup and content.
* `css/styles.css`: Stylesheet responsible for layout design, typography, and theme styling.
* `js/script.js`: Contains JavaScript functions for dynamic features and form handling.
* `images/`: Directory containing project image assets.
* `videos/`: Directory containing video media files.

## JavaScript Features
* **Contact Form Validation & Preview:** Ensures user entries are correct before submission and displays a live preview.
* **Dark/Light Mode:** Enables seamless switching between light and dark visual themes.
* **Project Filtering:** Allows filtering projects by specific tags or categories.

## How to Test
1. **Form Validation:** Open the contact form, leave fields blank or type invalid email formats, and submit to verify error prompts.
2. **Theme Switcher:** Click the Dark/Light mode toggle button to confirm page theme updates across the site.
3. **Project Filters:** Click category filter buttons on the portfolio section to verify projects filter correctly.
